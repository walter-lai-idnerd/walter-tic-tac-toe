# Tic-Tac-Toe Game

A simple two-player tic-tac-toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- **Two-player gameplay**: Alternating turns between X and O
- **3x3 grid**: Classic tic-tac-toe board
- **Auto-restart**: Game automatically restarts when someone wins or the board is full
- **No build required**: Just open in a browser or use Python's built-in server

## How to Play

1. Players alternate turns, with X going first
2. Click an empty cell to place your symbol
3. Win by getting three symbols in a row (horizontally, vertically, or diagonally)
4. When someone wins or the board fills up, the game automatically resets after 1 second
5. Play again!

## Running Locally

### Option 1: Using Python's HTTP Server (Recommended)

```bash
python -m http.server
```

Then open your browser and navigate to `http://localhost:8000`

### Option 2: Direct File Access

Simply open `index.html` in your web browser.
